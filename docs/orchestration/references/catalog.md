# Extended prompt catalog (moved)

This page has been superseded by the per-task [prompt catalog](/catalog/) — the same
37 task recipes, now one page each with structured frontmatter (`task`, `category`,
`beats`, `grounding`) instead of one long page of tables, and a sidebar nested by
category instead of a single scroll. The catalog's own reading conventions ("How to
read a recipe") and its guidance on how many plugins to reach for ("How many plugins")
now live on [the catalog's landing page](/catalog/#how-to-read-a-recipe). This page is
kept, unindexed from primary navigation, only so that external links made against the
old URL still resolve.
