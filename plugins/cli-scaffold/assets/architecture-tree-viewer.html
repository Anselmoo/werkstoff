cli-scaffold — architecture tree

Does every pillar the doctrine names have a file behind it?

Each badge below is a role the scaffold's own cli-scaffold.manifest.json declares for that file — the same gating keys verify_scaffold.py reads to decide pass/fail, not a guess made from the filename. A role with no file is drawn hollow and dashed in the legend. The fifth pillar, Unix composability, is behavioural — exit codes 0/1/2, data on stdout, diagnostics on stderr — so no file can carry its badge and it is deliberately not counted here.
