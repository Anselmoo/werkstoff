cupertino — review flow

Did this review actually finish?

A stage nobody reached is not a stage somebody skipped: a skip is a recorded decision with a reason attached, an unreached stage is an unfinished review.

The nine stages are cupertino's design techniques, run in a fixed order because each decides something the next depends on — which is why a stage nobody reached leaves a real hole rather than a missing formality. A stage that ran persisted a result. A stage explicitly skipped carries its own recorded reason. A stage never reached decided nothing, so no reason exists to read. Outline style says this as well as colour does, and every node also carries the state in words.

  • ran — solid green outline, result persisted
  • explicitly skipped — dashed amber outline, reason recorded
  • never reached — dotted muted outline, nothing decided
