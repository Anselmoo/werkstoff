✓ verified
the step read exactly the bytes its producer wrote (sha256 equal).
✗ broken
the bytes changed between the producer's write and this read. Something outside the traced steps touched the file.
! unverified
the file changed during the run, but no traced step wrote it, or it could not be hashed. Never a pass.
– source
an input that predates the run: nothing in it was produced here, so there is nothing to chain to.
path@n
the n-th version of a file in this run. A file rewritten in place gets a new version, and a consumer is checked against the latest version written before it read the file.
untraced step
a process the run spawned that left no record (a shell, a non-Python program). Its command is known; its calls and file I/O are not.
