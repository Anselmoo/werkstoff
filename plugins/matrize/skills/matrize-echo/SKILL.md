Vary the expression, hold the idiom.

The precondition matters more than anything else here: **the direction must already be
settled**. Echo takes a premise as given and explores how it can be said. If the premise
is still open, every variation inherits a decision nobody made, and the session will
mistake agreement about execution for agreement about direction.

If direction is open, stop and run `matrize-spread`.

## What may vary, and what may not

**May vary:** the ratio the type scale steps by, how much space separates groups, which
of the named roles carries emphasis in a given view, the radii series, motion timing
inside its class, the density of the layout.

**May not vary:** the roles themselves, what the dominant action colour *is*, the
premise, or anything the signed `BRIEF.md` fixed. A variation that changes one of those
is not an echo — it is a second proposal, and it belongs in a spread where it can be
argued for honestly.

## Inherited shell

Each variation is rendered in **the system's own shell**, not a neutral one. Variations
inside one idiom stay comparable regardless of chrome, so the fixed shell `spread`
needs would only make every option look less like itself.

This is the deliberate difference between the two skills, and it is worth stating on the
page so a reader who has seen a spread does not assume the same rules apply.

## Say what each variation costs

For each: one sentence on what it is better at, and one on what it gives up. A set of
variations with no stated trade-offs is a set of preferences, and invites the reader to
pick by taste — which is exactly the decision this plugin exists to replace with a
recorded one.

## No forced-choice gate here

`echo` does not write a choice record and is not gated by one. Variations inside a
settled idiom can legitimately all be acceptable, and several may ship for different
contexts. The forced choice belongs where the decision is structural, which is `spread`.

Still record which variation was adopted, and why, in `LEXIKON.md` alongside the element
it affects — otherwise the next session re-opens a question that was already answered.
