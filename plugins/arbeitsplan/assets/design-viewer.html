▶ agent
a dispatched model that builds, reviews or fixes. A wave's rows each run in their own agent worktree, side by side.
$ script
one declared command, run by a Bash-only runner. Dashed outline: an authored step, which the plan writes and verifies before anything runs it.
⇄ merge-gate
merges its wave into the integration branch and runs every gate; the target moves only when they are green.
‖ human gate
a person approves between runs. The dashed line across the graph is where one run ends and the next begins.
status
✓ done, green, approved or verified · ✗ red · ↻ stale · ∅ missing or still a stub · ○ pending · no mark: the run state records nothing for this node. A red outline marked ✗ rejected is the validator's refusal, not a run result.
overlap
a red dashed arc joins two rows that run at the same time and may write the same file.
