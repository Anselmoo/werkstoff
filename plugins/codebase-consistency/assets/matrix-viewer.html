Which module is furthest from the canon?

No matrix has been loaded into this template yet, so no module can be named the worst; a rendered report replaces this sentence with the worst module, its worst cell, and what the area's mean conformance implies.

A red cell is not "a module with a different style". It is a module whose answer to a convention question an alignment pass has to rewrite at every site counted inside the cell — so a red cell with a large site count is the expensive one, and a red cell with two sites is nearly free.

Reading the cells. Every cell prints its own key on a dark plate, so no cell has to be read by colour alone. Once /consistency-canonize has run, the key is the cell's distance from the chosen canon — ✓ aligned (green), ≈ partially aligned (amber), ✗ diverging (red) — followed by its site count, and a cell keyed “–” has no score yet. Before that, the key is a letter naming the variant in that cell: the two most frequent variants also get a hue each (blue and purple — never red, amber or green, which mean conformance here), the rest share one neutral fill, and the letter is what tells two variants apart. A cell with a dashed outline that reads “no data” has nothing recorded for that module × dimension pair.
