A red cell is not "a module with a different style". It is a module whose answer to a convention question an alignment pass has to rewrite at every site counted inside the cell — so a red cell with a large site count is the expensive one, and a red cell with two sites is nearly free.

Click a cell to see its detail — module, dimension, variant in use, and site count.
Reading the cells. Once /consistency-canonize has run, a cell's colour is its distance from the chosen canon — green aligned, amber partial, red diverging, as labelled in the legend below. Before that it shows variant-cluster identity instead: one hue per distinct variant, with no ranking implied. A hatched cell means no data was found for that module × dimension pair. The number printed inside a cell is its site count.
